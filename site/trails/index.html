lamb trails

(what she's up to...)

updates! updates! i'm busy updating the site... my poor sickly victorian child. checked off the tunes and comics pages this month!

finished off my uni projects. check out my pico-8 game go fishin' and my little comic back n forth!

implementing the jummbox synth in rust. since i write most of my games' music in jummbox, for my loose game engine project, i thought it would be nice to be able to play jummbox songs back directly rather than have to manually export them as wav/mp3 and loop them.

another thought: since jummbox already stores songs as a compact string in the url, i could store songs in that compact format instead of in bulky audio files. i make pixel-art games, so audio is by far the biggest storage sink in my games -- even though it doesn't need to be because it's representable by tracker data anyway...

i've started implementing the jummbox synth in rust, using the original typescript as a reference. i've finished a json song loader, and now that i can load songs for testing, i've been working on the synth itself... which has been taking a while! translating the typescript directly would be one thing, but since it is so messy (sorry LOL) i've been reorganizing it as i go... which takes time.

playing some retroslop. picked up final fantasy origins and enjoying it. (girl who's only plauyed delatrune voice) its fun to play games that make up deltarune's dna and see all the stuff it references without my knowing... the opening cutscene is straight up deltarune it's awesome. my self-assigned mission is to play many old games and absorb their cool game design
