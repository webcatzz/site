loop

_init()
called once when the game starts.
_update()
called 30 times per second, regardless of framerate.
_draw()
called every frame.
_update60()
similar to _update but called 60 times per second.

graphics

color([col])
sets the default color used when drawing. col defaults to 6.
cls([col])
fills the screen with a color and resets the clipping rectangle. col defaults to 0.

text

? is shorthand for print: ?"hello world",4,6

print acknowledges several special codes:

  • \#0 (set background color 0-f)
  • \f0 (set foreground color 0-f)
  • \^i (invert colors)
  • \^w (start wide characters)
  • \^-w (stop wide characters)
  • \^t (start tall characters)
  • \^-t (stop tall characters)
  • \^p (start pinball characters)
  • \^-p (stop pinball characters)
  • \a (beep)
print(str,x,y,[col])
print(str,[col])
prints a string at (x,y). (x,y) defaults to the current cursor position.

shapes

rect(x1,y1,x2,y2,[col])
draws a rectangle with opposite corners (x1,y1) and (x2,y2).
rectfill(x1,y1,x2,y2,[col])
similar to rect but draws a solid rectangle.
circ(x,y,r,[col])
draws a circle with center (x,y) and radius r.
circfill(x,y,r,[col])
similar to circ but draws a solid circle.
oval(x1,y1,x2,y2,[col])
draws an ellipse bounded by the rectangle with opposite corners (x1,y1) and (x2,y2).
ovalfill(x1,y1,x2,y2,[col])
similar to oval but drwas a solid oval.

input

buttons are referenced by index, as follows: 0=⬅ 1=➡ 2=⬆ 3=⬇ 4=🅾 5=❎

these indices are also stored in a set of global variables: ⬅ (shift+l), ➡ (shift+r), ⬆ (shift+u), ⬇ (shift+d), 🅾 (shift+o), and ❎ (shift+x).

btn([b],[pl])
returns a boolean indicating whether a button is currently pressed for some player. pl defaults to 0. if called without arguments, returns a bitfield of current input for both players.
btnp([b],[pl])
similar to btn but only returns true if the button was pressed in the time since the last frame.

map

mset(x,y,val)
sets the map tile at (x,y).
mget(x,y)
gets the map tile at (x,y). if (x,y) is outside the map, returns 0.
map([tx,ty],[sx,sy],[tw,th],[layers])
draws a portion of the map from (tx,ty) with dimensions (tw,th) at screen coordinates (sx,sy).
