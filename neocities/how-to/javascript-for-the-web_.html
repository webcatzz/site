this guide assumes you have a solid grasp on using javascript but none at all on interacting with the DOM.

what's the DOM?

the DOM, or the Document Object Model, is how every html page is structured. try right clicking anywhere on this page and clicking "inspect". you've just opened the inspector—a visualization of the DOM.

the DOM is a tree of nodes. nodes (or elements) are the individual components of a page—they're displayed in the inspector like html tags. they are organized in a tree, where each node has a parent (element outside) and any number of children (elements inside). look at the following html:


<div>
  <h2>hello!</h2>
  <p>lorem ipsum</p>
</div>

the div is the parent of both the heading and the paragraph. the heading and the paragraph are both children of the div.

interacting with the DOM

javascript code can interact with the dom using the document object. document is a door into the DOM—javascript code can't access the DOM any other way.
